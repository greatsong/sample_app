생활 데이터 웹앱 만들기
샘플 앱시작부록

Project Based Web Textbook

내 생활 데이터를 보여주는 웹앱을 만든다.

완성본 체험에서 시작해 GitHub Pages 배포, 바이브코딩 작업법, 공개 데이터 API, Google Sheets 저장, Apps Script 프록시, 자기화와 발표까지 이어지는 프로젝트형 웹교재입니다.

0장부터 시작 완성 앱 보기

전면 재작성 기준
기존 문장과 형식은 버리고, 목차와 기능 요소만 남겼습니다. 참고 레포의 형식처럼 같은 앱이 단계마다 강해지는 Phase 구조와 교사용 운영 포인트, 우와 모먼트, 체크리스트를 넣었습니다.

수업 전체 흐름

Phase 0완성본을 먼저 해부하기

코딩 전 앱을 사용자처럼 써 보고 데이터 흐름을 스케치합니다.

Phase 1내 앱 URL 만들기

GitHub Pages로 각자 수정할 앱 주소를 만듭니다.

Phase 2바이브코딩 작업법

AI에게 통째로 맡기지 않고 작은 수정과 검증을 반복합니다.

Phase 3공개 데이터 붙이기

날씨와 급식 데이터를 연결해 첫 API 성공 경험을 만듭니다.

Phase 4사용자 행동 저장하기

급식 투표를 Google Sheets에 저장합니다.

Phase 5비밀키 숨기는 프록시

Apps Script로 버스 API 키를 보호합니다.

Phase 6내 생활권 앱으로 리디자인

샘플을 우리 학교와 정류소에 맞게 바꿉니다.

Phase 7발표와 갤러리

데이터 흐름과 보안 판단을 설명합니다.
