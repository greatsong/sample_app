0. 완성본 먼저 체험하기

10분관찰코드 수정 없음

초보자 수업은 완성된 화면을 먼저 보고 시작합니다. 학생이 오늘 무엇을 만들지 모르면 코드 설명이 전부 낯선 단어가 됩니다.

이번 목표

샘플 앱을 열고 날씨, 급식, 버스, 투표 영역이 어떤 역할을 하는지 말로 설명합니다.

  1. 샘플 앱을 엽니다.
  2. 날씨 카드에서 온도, 습도, 바람 정보를 찾습니다.
  3. 급식 카드에서 오늘과 내일 메뉴가 나뉘어 보이는지 확인합니다.
  4. 버스 카드에서 관악11 도착 문구를 확인합니다.
  5. 투표 버튼을 누르면 어떤 저장소가 필요할지 예상해 봅니다.
교사용 메모

처음부터 Apps Script나 CORS를 설명하지 않습니다. 먼저 “화면에 보이는 데이터가 어디서 왔을까?”를 묻고, 학생의 답을 들은 뒤 API 개념으로 연결합니다.

1. 파일 구조 이해하기

15분코드 읽기

이 프로젝트는 많은 기능이 있지만 파일 역할은 단순하게 나눌 수 있습니다.

index.html: 화면의 뼈대
css/style.css: 색상과 배치
js/config.js: 학교, 정류소, 프록시 주소 같은 설정
js/adapters/api-services.js: 날씨·급식·버스 API 호출
js/app.js: 버튼 클릭, 카드 그리기, 투표 처리
apps-script/Code.gs: 버스 키 숨기기, 메일 알림, 투표 저장 대행

학생 활동

  1. GitHub에서 각 파일을 하나씩 엽니다.
  2. 파일 이름 옆에 “화면”, “디자인”, “설정”, “동작”, “서버 역할” 중 하나를 적습니다.
  3. 앱에서 보이는 문구 하나를 골라 어느 파일에 있는지 찾아봅니다.
주의

초보자에게 전체 코드를 한 번에 설명하지 않습니다. “오늘 고칠 파일 하나”를 정하고 그 파일만 집중해서 봅니다.

2. 날씨 API 붙이기

20분공개 API키 없음

Open-Meteo는 API 키 없이 현재 날씨를 가져올 수 있습니다. 첫 API 실습은 키가 없는 API로 시작해야 실패 지점이 줄어듭니다.

weather: { enabled: true, label: "서울", latitude: 37.5665, longitude: 126.9780 }

확인 질문

  • 서울의 위도와 경도는 어디에 적혀 있나요?
  • 날씨 카드에 표시되는 값은 API 응답 중 어떤 필드일까요?
  • API 키가 없는 API와 키가 필요한 API는 무엇이 다를까요?
교사용 메모

날씨는 “성공 경험”입니다. 여기서 API 호출, JSON, 화면 표시의 기본 감각을 잡고 급식·버스로 넘어갑니다.

3. 오늘과 내일 급식 표시하기

25분NEIS날짜 처리

급식은 학생에게 익숙한 데이터입니다. 이 수업에서는 “가장 가까운 급식일”이 아니라 “오늘과 내일”을 고정으로 보여줍니다. 그래야 날짜가 틀린 것처럼 보이는 문제를 줄일 수 있습니다.

schoolMeal: { educationOfficeCode: "B10", schoolCode: "7010073", schoolName: "당곡고등학교", mealCode: "2", mealDate: "" }

실습

  1. 샘플 앱에서 오늘과 내일 급식 제목을 찾습니다.
  2. 중식 메뉴가 몇 개인지 세어 봅니다.
  3. 코드에서 `mealCode: "2"`가 중식을 뜻한다는 점을 표시합니다.
  4. `mealDate`가 비어 있으면 오늘과 내일을 자동 계산한다는 점을 확인합니다.

4. 급식 투표를 Google Sheets에 저장하기

35분저장교사용 준비 필요

브라우저 저장소는 내 컴퓨터에만 저장됩니다. 친구들과 같은 투표 결과를 보려면 공용 저장소가 필요합니다. 이 교재에서는 초보자가 눈으로 확인하기 쉬운 Google Sheets를 사용합니다.

투표 버튼 클릭
Apps Script Web App으로 전송
Google Sheets의 meal_votes 탭에 한 줄 추가
voteKey별로 표 수 계산
웹앱에 다시 표시

시트에 저장되는 열

createdAt | mealDate | mealTitle | menuName | voteKey | userAgent

`voteKey`는 `20260526:칼슘강화기장밥`처럼 날짜와 메뉴를 합친 값입니다. 같은 메뉴라도 날짜가 다르면 다른 투표로 계산합니다.

교사용 준비

Google Sheets 쓰기는 Apps Script 권한 승인이 필요합니다. `MEAL_VOTE_SHEET_ID`를 Script Properties에 넣고, 새 배포 버전에서 Sheets 권한을 승인해야 합니다. 승인 전에는 기존 버스 프록시가 멈추지 않도록 배포 버전을 바꾸지 않습니다.

5. 마을버스 도착 정보 붙이기

30분비밀키Apps Script

서울 버스 API 키는 GitHub Pages 코드에 넣지 않습니다. GitHub Pages는 공개 웹사이트라서 키가 노출될 수 있습니다. 그래서 Apps Script가 중간 서버 역할을 합니다.

GitHub Pages 웹앱
Apps Script Web App URL
Script Properties의 BUS_API_KEY
서울 버스 API
도착 정보 JSON 반환

설정값

villageBus: { enabled: true, proxyUrl: "https://script.google.com/macros/s/.../exec", arsId: "21347", routeName: "관악11" }

학생 확인

  • `arsId`는 정류소번호입니다.
  • `routeName`은 찾을 버스 노선명입니다.
  • `proxyUrl`은 Apps Script 배포 주소입니다.
헷갈리는 지점

서울 버스 API는 Google Cloud에서 찾는 API가 아닙니다. Google Cloud는 Apps Script 같은 Google API를 관리하는 곳이고, 버스 정보는 서울시 버스 Open API에서 확인합니다.

6. 나만의 학교와 정류소로 바꾸기

30분개인화최종 점검

마지막 본문 실습은 완성본을 내 생활권 앱으로 바꾸는 단계입니다. 한 번에 전부 고치지 않고 날씨, 급식, 버스를 하나씩 바꾼 뒤 화면을 확인합니다.

바꿀 설정값

날씨: label, latitude, longitude
급식: educationOfficeCode, schoolCode, schoolName, mealCode, mealDate
버스: proxyUrl, arsId, routeName

실습 순서

  1. 현재 샘플 앱이 정상 작동하는지 확인합니다.
  2. `js/config.js`의 원래 값을 메모합니다.
  3. 날씨 지역만 바꾸고 새로고침합니다.
  4. 학교 급식 설정만 바꾸고 새로고침합니다.
  5. 정류소번호와 노선명만 바꾸고 새로고침합니다.
  6. 급식 투표가 Google Sheets에 저장되는지 확인합니다.
  7. GitHub Pages 주소에서 같은 화면이 열리는지 확인합니다.
주의

세 기능을 한 번에 바꾸면 어디서 오류가 났는지 찾기 어렵습니다. 하나를 바꾸고 저장, 새로고침, 확인까지 끝낸 뒤 다음 기능으로 넘어갑니다.

교사용 확장. 도착 5분 전 메일 알림

확장트리거교사용

메일 알림은 학생 본문이 아니라 교사용 운영 또는 확장 활동입니다. 권한 승인, 시간 기반 트리거, 이메일 발송이 들어가므로 본문 실습 흐름과 분리합니다.

GitHub Pages는 1분마다 혼자 실행될 수 없습니다. 그래서 Apps Script의 시간 기반 트리거를 사용합니다.

Script Properties

  • `BUS_ALERT_EMAIL`: 알림 받을 이메일
  • `BUS_ALERT_ARS_ID`: 정류소번호, 기본값 `21347`
  • `BUS_ALERT_ROUTE_NAME`: 노선명, 기본값 `관악11`
  • `BUS_ALERT_COOLDOWN_MINUTES`: 중복 메일 방지 시간, 기본값 `10`

트리거 설정

  1. Apps Script 왼쪽에서 트리거를 엽니다.
  2. 실행 함수로 `checkBusAndSendMail`을 고릅니다.
  3. 이벤트 소스는 시간 기반으로 고릅니다.
  4. 분 단위 타이머, 1분마다 실행으로 설정합니다.
교사용 메모

메일 주소와 몇 분 전 알림 설정을 공개 화면에서 아무나 바꾸게 하면 안 됩니다. 필요하면 관리자 PIN 같은 보호 장치를 붙인 뒤 Apps Script가 설정을 저장하는 구조로 확장합니다.

오류 해결 카드

NO_BUS_API_KEY

Apps Script Script Properties에 `BUS_API_KEY`가 없습니다.

SERVICE KEY IS NOT REGISTERED

키가 틀렸거나 해당 서울 버스 서비스에 승인된 키가 아닐 수 있습니다.

버스 API가 없어요

Google Cloud에서 찾고 있는지 확인합니다. 서울 버스 정보는 `https://api.bus.go.kr/` 쪽입니다.

급식 날짜가 이상해요

한국 시간 기준 오늘과 내일을 조회합니다. `mealDate`에 특정 날짜가 들어 있으면 그 날짜부터 이틀을 봅니다.

투표 저장이 안 돼요

Google Sheets 권한 승인, `MEAL_VOTE_SHEET_ID`, Apps Script 새 버전 배포 여부를 확인합니다.
