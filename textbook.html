생활 데이터 웹앱 만들기

완성본 체험에서 시작해 파일 구조, 날씨 API, 급식 API, Google Sheets 투표 저장, 버스 프록시, 나만의 학교/정류소 설정까지 챕터별로 따라가는 왕초보용 웹교재입니다.

이제 한 페이지 요약본이 아니라 챕터별 페이지로 나눴습니다. 각 장은 목표, 완성 화면, 따라하기, 확인 체크리스트, 자주 나는 오류, AI 프롬프트 순서로 진행합니다. 전체 원문은 Markdown 원문에도 유지되어 있습니다.

수업 흐름

0장. 완성본 체험하기코드를 고치기 전에 앱이 보여주는 데이터와 화면 흐름을 관찰합니다.1장. 파일 구조 이해하기HTML, CSS, JavaScript, config, Apps Script 파일 역할을 구분합니다.2장. 날씨 API 붙이기키가 필요 없는 Open-Meteo API로 첫 API 연결을 성공시킵니다.3장. 급식 오늘/내일 표시하기NEIS 급식 API에서 오늘과 내일 중식을 가져옵니다.4장. 급식 투표 저장하기투표 버튼과 Google Sheets 저장 흐름을 연결합니다.5장. 버스 도착 정보 붙이기Apps Script 프록시로 버스 API 키를 숨기고 도착 정보를 표시합니다.6장. 나만의 학교/정류소로 바꾸기샘플 설정을 내 학교와 내 정류소 기준으로 바꿉니다.부록. 설정과 오류 해결Apps Script, 메일 알림, DB 확장, 문제 해결을 분리해서 봅니다.마무리 활동1분 발표와 자기평가로 프로젝트를 정리합니다.

수업 원칙

  • 한 번에 하나만 바꾸고 바로 새로고침합니다.
  • API 키와 비밀번호는 GitHub에 올리지 않습니다.
  • Console 오류는 실패가 아니라 다음 질문 재료입니다.
  • AI 답변은 그대로 믿지 않고 실행 결과로 검증합니다.
