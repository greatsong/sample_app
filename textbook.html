생활 데이터 웹앱 만들기
샘플 앱교재 목차부록마무리

Project Based Web Textbook

내 생활 데이터를 보여주는 웹앱을 만든다.

완성본 체험에서 시작해 GitHub Pages 배포, 바이브코딩 작업법, 공개 데이터 API, Google Sheets 저장, Apps Script 프록시, 자기화와 발표까지 이어지는 프로젝트형 웹교재입니다.

0장부터 시작완성 앱 보기Markdown 원문

전면 재작성 기준
기존 설명 문장을 버리고, 목차와 기능 요소만 남겼습니다. 구조는 Phase형 바이브코딩 수업처럼 “같은 앱이 점점 강해지는 흐름”으로, 내용은 실제 데이터 운영 프로젝트처럼 “데이터 출처, 저장, 보안, 운영, 발표”가 남도록 다시 설계했습니다.

수업 전체 흐름

Phase 0완성본을 먼저 해부하기

코드를 건드리기 전에 생활 데이터 앱이 어떤 문제를 해결하는지 관찰하고, 앞으로 바꿀 방향을 정합니다.

Phase 1내 앱 URL 만들기

GitHub Pages로 각자 수정할 수 있는 웹앱 주소를 만들고, 수정-커밋-배포 루프를 익힙니다.

Phase 2바이브코딩 작업법 익히기

AI에게 한 번에 완성품을 맡기지 않고, 작은 수정과 검증을 반복하는 웹앱 제작 루틴을 익힙니다.

Phase 3공개 데이터 붙이기

키 없이 쓸 수 있는 날씨와 학교 급식 데이터를 연결해 첫 API 성공 경험을 만듭니다.

Phase 4사용자 행동 저장하기

급식 투표를 Google Sheets에 저장하면서 브라우저 안 데이터와 공용 저장 데이터의 차이를 배웁니다.

Phase 5비밀키 숨기는 프록시 만들기

버스 API 키를 공개 코드에 넣지 않고 Apps Script 프록시를 통해 안전하게 실시간 도착 정보를 가져옵니다.

Phase 6내 생활권 앱으로 리디자인하기

샘플 앱을 우리 학교, 우리 정류소, 우리 반 사용자를 위한 생활 데이터 도구로 바꿉니다.

Phase 7발표와 갤러리

기능 자랑이 아니라 데이터 흐름과 보안 판단을 설명하고, 친구 피드백을 다음 버전 계획으로 바꿉니다.

Appendix설정과 오류 해결

Apps Script, API 키, Console 오류, 교사용 운영 체크리스트를 따로 모았습니다.

Finish마무리 활동

1분 발표, 자기평가, 갤러리 피드백으로 프로젝트를 정리합니다.

이 교재의 수업 원칙

완성본 먼저

개념 설명보다 먼저 작동하는 앱을 만지고 질문을 만듭니다.

작게 바꾸기

한 번에 한 파일, 한 설정만 바꾸고 바로 확인합니다.

데이터 흐름 설명

화면보다 데이터가 어디서 와서 어디에 저장되는지 말하게 합니다.

AI 답변 검증

AI는 조수이고, 최종 판단은 실행 결과와 오류 기록으로 합니다.
