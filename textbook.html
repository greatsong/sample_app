생활 데이터 웹앱 만들기

GitHub Pages, 바이브 코딩, Google Sheets, 날씨, 마을버스, NEIS 급식, 투표, DB 연동까지 이어지는 왕초보용 교재입니다.

교재 목표

  • GitHub Pages에 정적 웹앱을 배포합니다.
  • HTML, CSS, JavaScript의 역할을 구분합니다.
  • AI에게 작은 단위로 코딩 요청을 하고 결과를 검토합니다.
  • Open API 문서에서 URL, 파라미터, 인증키 위치를 찾습니다.
  • 날씨, 마을버스, 급식 데이터를 웹 화면에 표시합니다.
  • 급식 메뉴 투표 기능을 만들고 localStorage와 DB의 차이를 설명합니다.

01. GitHub Pages 첫 배포

GitHub 가입 후 새 저장소를 만들고 `index.html`, `css`, `js` 파일을 올립니다. Settings > Pages에서 branch 배포를 선택한 뒤 1~3분 기다리면 배포 주소가 생성됩니다.

  • `index.html`은 저장소 루트에 있어야 합니다.
  • 파일명 대소문자를 확인합니다.
  • Pages에 올라간 파일은 공개될 수 있으므로 비밀키를 넣지 않습니다.

02. 바이브 코딩 흐름

AI에게 한 번에 큰 앱을 맡기지 말고 작은 변경 단위로 요청합니다.

index.html과 css/style.css를 기준으로 급식 투표 카드의 버튼을 더 눈에 잘 띄게 만들어줘. 기존 색상은 유지하고 모바일에서도 버튼이 카드 밖으로 나가지 않게 해줘.

03. Google Sheets 연동

Google Sheets는 DB를 배우기 전 표 기반 데이터를 설명하기 좋은 도구입니다. Spreadsheet ID, Range, API Key의 역할을 익히고 공개 읽기 데이터부터 시작합니다.

04. Open API 3종

날씨

Open-Meteo를 사용합니다. 키 없이 동작하며 서울 위도/경도가 기본값입니다.

마을버스

서울특별시_버스도착정보조회 서비스를 사용합니다. 공공데이터포털에서 활용신청 후 인증키, 정류소 ID, 노선 ID를 `js/config.js`에 입력합니다.

NEIS 급식

NEIS 급식식단정보를 사용합니다. 기본 샘플은 선린인터넷고등학교이며, 특정 날짜는 `YYYYMMDD` 형식으로 지정합니다.

05. 버스 5분 전 알림

GitHub Pages만으로는 백그라운드 실행이 안 되므로 알림 서버가 필요합니다. 수업용 추천은 Google Apps Script입니다.

function checkBusAndSendMail() {
  const email = "your-email@example.com";
  const minutesLeft = 5;
  if (minutesLeft <= 5) {
    MailApp.sendEmail(email, "버스 알림", "버스가 약 5분 뒤 도착합니다.");
  }
}

실제 구현에서는 `minutesLeft` 대신 버스 API 응답의 도착예정시간 초 단위 필드, 예를 들어 `exps1`, `traTime1` 등을 분으로 바꿔 비교합니다.

06. 급식 메뉴 투표

급식 API에서 메뉴를 가져오고 각 메뉴 옆에 투표 버튼을 만듭니다. 처음에는 localStorage에 저장합니다.

  • 장점: 서버 없이 GitHub Pages에서 바로 동작합니다.
  • 한계: 같은 브라우저에서만 유지됩니다.
  • 확장: Supabase DB로 바꾸면 여러 학생이 같은 결과를 공유할 수 있습니다.

07. DB 연동

여러 사람이 같은 투표 결과를 보려면 DB가 필요합니다. Supabase에서 `meal_votes` 테이블을 만들고 publishable key만 브라우저에 넣습니다. service role key와 DB 비밀번호는 절대 공개 코드에 넣지 않습니다.

create table meal_votes (
  id bigint generated by default as identity primary key,
  menu_name text not null,
  created_at timestamp with time zone default now()
);
