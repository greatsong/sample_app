# 생활 데이터 웹앱 만들기

완성본 체험에서 시작해 GitHub Pages 배포, 바이브코딩 작업법, 공개 데이터 API, Google Sheets 저장, Apps Script 프록시, 자기화와 발표까지 이어지는 웹교재입니다.

## 장별 흐름

0. 완성본 체험하기: 생활 데이터 앱의 네 영역을 관찰합니다.
1. 내 앱 URL 만들기: GitHub Pages로 실제 URL을 만듭니다.
2. 바이브코딩 작업법 익히기: 한 번에 하나만 바꾸고 검증합니다.
3. 공개 데이터 붙이기: 날씨와 급식 데이터를 연결합니다.
4. 사용자 행동 저장하기: 급식 투표를 Google Sheets에 저장합니다.
5. 비밀키 숨기는 프록시 만들기: Apps Script로 버스 API 키를 보호합니다.
6. 내 생활권 앱으로 리디자인하기: 우리 학교와 정류소에 맞춥니다.
7. 발표와 갤러리: 데이터 흐름 중심으로 발표합니다.

## 수업 원칙

- 한 번에 하나만 바꾸고 바로 새로고침합니다.
- API 키와 비밀번호는 GitHub에 올리지 않습니다.
- Console 오류는 실패가 아니라 다음 질문 재료입니다.
- AI 답변은 그대로 믿지 않고 실행 결과로 검증합니다.
