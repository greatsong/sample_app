Chapter 7

발표와 갤러리

내 앱이 어떤 문제를 해결하는지 데이터 흐름 중심으로 설명합니다.

이전 장마무리

우와 모먼트
친구들이 내 앱을 직접 써보고 좋은 점과 다음 버전 아이디어를 남깁니다.

목표

  • 앱의 기능이 아니라 데이터 흐름을 설명합니다.
  • 보안상 숨긴 값과 공개해도 되는 값을 구분합니다.
  • 피드백을 다음 commit 계획으로 바꿉니다.

따라하기

  1. 앱 URL을 열고 핵심 카드 3개를 보여줍니다.
  2. 날씨·급식·투표·버스 데이터가 어디서 오는지 말합니다.
  3. Google Sheets와 Apps Script가 맡는 일을 설명합니다.
  4. 친구에게 실제로 써보게 하고 피드백을 받습니다.
  5. 다음 버전에 고칠 점 하나를 GitHub issue 또는 메모로 남깁니다.

체크리스트

  • 내 앱 URL이 열린다.
  • API 키를 어디에 숨겼는지 설명할 수 있다.
  • 친구 피드백을 적어도 3개 받았다.
  • 다음 버전에서 바꿀 점을 하나 정했다.

AI 프롬프트

내 생활 데이터 웹앱 발표를 1분짜리로 준비하려고 해. 문제, 데이터 출처, 내가 바꾼 점, 보안상 신경 쓴 점, 다음 버전 계획 순서로 발표 대본을 만들어줘.
