Chapter 5

비밀키 숨기는 프록시 만들기

버스 API 키를 GitHub Pages에 넣지 않고 Apps Script가 대신 호출하게 합니다.

이전 장다음 장

우와 모먼트
공개 웹앱인데도 비밀키를 숨기고 실시간 버스 정보를 가져옵니다.

목표

  • API 키 노출, CORS, HTTP/HTTPS 문제가 왜 생기는지 이해합니다.
  • Apps Script 프록시 구조를 설명합니다.
  • 정류소번호와 노선명을 바꿔 내 버스 카드로 만듭니다.

따라하기

  1. 서울 버스 API 키를 준비합니다.
  2. Apps Script Script Properties에 BUS_API_KEY를 넣습니다.
  3. apps-script/Code.gs를 붙여넣고 새 배포를 만듭니다.
  4. 실행 사용자는 나, 액세스 권한은 모든 사용자로 설정합니다.
  5. Web App URL을 앱 설정의 proxyUrl에 넣습니다.
  6. arsId와 routeName을 바꾸고 버스 카드 상태를 확인합니다.

체크리스트

  • BUS_API_KEY가 GitHub 파일 안에 없다.
  • proxyUrl은 /exec로 끝난다.
  • 정류소번호와 노선명이 실제 값이다.
  • 버스 카드가 실시간 연결 상태다.

AI 프롬프트

GitHub Pages에서 버스 API 키를 직접 넣지 않고 Apps Script 프록시를 쓰는 이유를 초보자에게 설명해줘. 비밀키 노출, CORS, HTTPS 문제를 쉬운 말로 풀어줘.
