Phase 3

공개 데이터 붙이기

키 없이 쓸 수 있는 날씨와 학교 급식 데이터를 연결해 첫 API 성공 경험을 만듭니다.

이전 장다음 장

우와 모먼트
지역과 학교 설정만 바꿨는데 내 생활권 데이터가 화면에 들어옵니다.
교사용 운영 포인트
  • 첫 API는 키가 필요 없는 날씨로 시작합니다.
  • 급식은 학생 생활과 바로 연결되지만 휴일에는 데이터가 없을 수 있습니다.
  • Network 탭은 요청, 성공, 데이터 도착 세 가지만 보게 합니다.

날씨 데이터

지역 이름은 화면 라벨이고 실제 날씨는 위도와 경도 기준으로 가져옵니다. 학생이 라벨만 바꾸면 데이터가 바뀐다고 오해하지 않게 합니다.

weather: { enabled: true, label: "서울", latitude: 37.5665, longitude: 126.9780 }

급식 데이터

NEIS 급식은 학교 이름만으로 가져오지 않습니다. 교육청 코드, 학교 코드, 급식 구분, 날짜가 함께 필요합니다.

schoolMeal: { enabled: true, educationOfficeCode: "B10", schoolCode: "7010073", schoolName: "당곡고등학교", mealCode: "2", mealDate: "" }

AI 프롬프트

Open-Meteo와 NEIS 급식 설정에서 각 값이 무슨 뜻인지 초보자에게 설명해줘.
