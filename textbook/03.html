Chapter 3

3장. 급식 오늘/내일 표시하기

NEIS 급식 API에서 오늘과 내일의 중식 메뉴를 가져옵니다.

목차이전 장다음 장

이번 목표

학교 급식 API 설정값을 이해하고 오늘과 내일 급식을 화면에 표시합니다. 학교를 바꾸려면 학교 이름만 바꾸는 것이 아니라 교육청 코드와 학교 코드도 함께 바꿔야 합니다.

따라하기

  1. js/config.js에서 schoolMeal 설정을 찾습니다.
  2. educationOfficeCode, schoolCode, schoolName을 확인합니다.
  3. mealCode가 "2"인지 확인합니다. "2"는 중식입니다.
  4. mealDate가 비어 있는지 확인합니다.
  5. 저장하고 새로고침합니다.

샘플 설정

schoolMeal: {
  enabled: true,
  educationOfficeCode: "B10",
  schoolCode: "7010073",
  schoolName: "당곡고등학교",
  mealCode: "2",
  mealDate: ""
}

mealDate가 비어 있으면 한국 시간 기준 오늘과 내일을 자동으로 조회합니다. 특정 날짜부터 보고 싶으면 20260526처럼 넣고, 실습이 끝나면 다시 비웁니다.

체크리스트

  • 급식 카드가 오늘과 내일로 나뉩니다.
  • mealCode: "2"가 중식이라는 점을 설명할 수 있습니다.
  • mealDate를 비우면 자동 날짜가 사용됩니다.
  • 학교를 바꾸려면 교육청 코드와 학교 코드가 필요하다는 점을 압니다.

자주 나는 오류

  • 급식 날짜가 이상하면 mealDate에 특정 날짜가 남아 있는지 확인합니다.
  • 메뉴가 없으면 휴일, 방학, NEIS 데이터 공백일 수 있습니다.
  • 학교가 바뀌지 않으면 교육청 코드와 학교 코드를 함께 확인합니다.

AI 프롬프트

NEIS 급식 API 설정에서 educationOfficeCode, schoolCode, schoolName,
mealCode, mealDate가 각각 무슨 뜻인지 초보자에게 설명해줘.
