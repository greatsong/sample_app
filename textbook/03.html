Chapter 3

공개 데이터 붙이기

키가 필요 없는 날씨와 공개 급식 데이터를 먼저 성공시켜 API 감각을 잡습니다.

이전 장다음 장

우와 모먼트
지역과 학교 설정만 바꿨는데 내 생활권 데이터가 화면에 들어옵니다.

목표

  • Open-Meteo 날씨 API와 NEIS 급식 API의 역할을 이해합니다.
  • 좌표, 교육청 코드, 학교 코드 같은 설정값을 안전하게 바꿉니다.
  • Network 탭에서 요청 성공과 실패를 확인합니다.

따라하기

  1. 기본 샘플 앱이 정상 작동하는지 확인합니다.
  2. weather.label, latitude, longitude만 바꾸고 확인합니다.
  3. 급식의 educationOfficeCode, schoolCode, schoolName을 찾습니다.
  4. 오늘과 내일 급식 카드가 비어 있지 않은지 확인합니다.
  5. API 요청 주소와 응답 상태를 Network 탭에서 봅니다.

체크리스트

  • 날씨와 급식은 서로 다른 API에서 온다는 점을 안다.
  • 좌표는 문자열이 아니라 숫자로 둔다.
  • 급식 공백과 코드 오류를 구분해 본다.

AI 프롬프트

내 웹앱에서 날씨와 급식 API 설정을 바꾸려고 해. 한 번에 다 바꾸지 않고 안전하게 확인하는 순서를 알려줘. Network 탭에서 무엇을 보면 되는지도 설명해줘.
