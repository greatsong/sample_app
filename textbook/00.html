Phase 0

완성본을 먼저 해부하기

코드를 건드리기 전에 생활 데이터 앱이 어떤 문제를 해결하는지 관찰하고 앞으로 바꿀 방향을 정합니다.

목차다음 장

우와 모먼트
친구 폰에서도 같은 앱이 열리고, 날씨·급식·버스 데이터가 실제로 바뀌는 것을 확인합니다.
교사용 운영 포인트
  • 첫 시간에는 설명보다 완성본 체험을 먼저 둡니다.
  • 기능 이름보다 데이터가 어디서 오고 누가 쓰는지 말하게 합니다.
  • 공개 데이터, 사용자 입력 데이터, 비밀키가 필요한 데이터를 구분하게 합니다.

학생 활동

  • 날씨, 급식, 투표, 버스 카드를 찾아 색으로 표시합니다.
  • 각 카드의 데이터 출처, 사용자 행동, 저장 여부를 기록합니다.
  • 급식 투표를 누른 뒤 새로고침해 숫자가 유지되는지 봅니다.
  • 내 학교 생활에 더 붙이고 싶은 데이터 한 가지를 제안합니다.

개념 정리

날씨와 급식은 공개 API에서 읽어옵니다. 투표는 사용자가 새로 만드는 데이터입니다. 버스는 비밀키가 필요하므로 브라우저가 직접 부르지 않고 Apps Script가 대신 호출합니다.
