샘플 앱목차

Chapter 0

완성본 체험하기

코드를 고치기 전에 생활 데이터 앱이 무엇을 보여주는지 먼저 만져봅니다.

목차다음 장

우와 모먼트
친구 폰에서도 같은 앱이 열리고, 날씨·급식·버스 데이터가 실제로 바뀌는 것을 확인합니다.
목표
  • 생활 데이터 웹앱의 네 영역을 구분합니다.
  • API가 외부 데이터를 가져오는 통로라는 점을 설명합니다.
  • 비밀키가 공개 웹페이지에 들어가면 안 되는 이유를 말합니다.
산출물

관찰 기록, 궁금한 점 3개, 바꾸고 싶은 생활 데이터 후보 1개

따라하기

  1. 완성본 URL을 열고 날씨, 급식, 투표, 버스 영역을 찾습니다.
  2. 급식 투표 버튼을 눌러 화면 변화와 새로고침 뒤 상태를 봅니다.
  3. 버스 카드 상태 문구를 기록합니다.
  4. 내 학교 생활에 붙이고 싶은 데이터 한 가지를 적습니다.

체크리스트

  • 완성본 주소를 열 수 있다.
  • 날씨, 급식, 투표, 버스 카드가 하는 일을 구분할 수 있다.
  • API 키와 비밀번호는 GitHub에 올리면 안 된다는 점을 안다.

자주 나는 오류

  • 예전 화면이 보이면 강력 새로고침을 합니다.
  • 급식이 비어 있으면 주말, 방학, NEIS 데이터 공백일 수 있습니다.

AI 프롬프트

생활 데이터 웹앱 완성본을 관찰했어. 날씨, 급식, 투표, 버스 기능이 각각 어떤 데이터를 보여주는지 초보자 눈높이로 설명해줘.
