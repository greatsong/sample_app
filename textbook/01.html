Chapter 1

내 앱 URL 만들기

GitHub Pages로 내가 고칠 웹앱을 인터넷에 올립니다.

이전 장다음 장

우와 모먼트
내 저장소 주소가 아니라, 친구에게 보낼 수 있는 실제 웹앱 URL이 생깁니다.

목표

  • GitHub 저장소와 GitHub Pages의 차이를 이해합니다.
  • 샘플 앱을 내 계정으로 가져와 배포합니다.
  • 수정, commit, 배포, 새로고침의 루프를 경험합니다.

따라하기

  1. 샘플 저장소를 내 계정으로 복사합니다.
  2. Settings > Pages에서 배포 브랜치를 확인합니다.
  3. index.html의 작은 문구 하나만 바꿉니다.
  4. commit 후 1~2분 기다리고 Pages URL을 새로고침합니다.
  5. 친구에게 URL을 보내 열리는지 확인합니다.

체크리스트

  • 저장소 주소와 웹앱 주소를 구분할 수 있다.
  • commit 후 배포 반영까지 시간이 걸린다는 점을 안다.
  • 수정 전 원래 값을 메모했다.

자주 나는 오류

  • 404가 뜨면 Pages 설정, 파일 이름, 배포 대기 시간을 차례로 확인합니다.
  • 친구는 안 열리면 저장소 공개 여부와 URL 오타를 봅니다.

AI 프롬프트

GitHub 저장소 주소와 GitHub Pages 웹사이트 주소의 차이를 초보자에게 설명해줘. commit 후 바로 안 바뀌는 이유도 알려줘.
