샘플 앱목차

Phase 1

내 앱 URL 만들기

GitHub Pages로 각자 수정할 수 있는 웹앱 주소를 만들고 수정-커밋-배포 루프를 익힙니다.

이전 장다음 장

우와 모먼트
저장소 주소가 아니라 친구에게 보낼 수 있는 실제 웹앱 URL이 생깁니다.
교사용 운영 포인트
  • 성공 기준은 멋진 수정이 아니라 URL이 열리는 것입니다.
  • 저장소 URL과 Pages URL을 계속 구분시킵니다.
  • 404가 실패가 아니라 배포 대기일 수 있음을 먼저 알려줍니다.

따라하기

  1. 샘플 저장소를 내 계정으로 복사합니다.
  2. Pages 설정 또는 Actions 배포 상태를 확인합니다.
  3. index.html의 문구 하나만 바꿉니다.
  4. commit 후 1~2분 기다리고 Pages URL을 새로고침합니다.
  5. 친구 기기에서 URL이 열리는지 확인합니다.

오류 진단

404가 뜨면 Pages 설정, 파일 이름, 배포 대기 시간을 차례로 봅니다. 수정했는데 그대로라면 캐시, 배포 대기, 다른 파일 수정 중 하나입니다.

AI 프롬프트

GitHub 저장소 주소와 GitHub Pages 주소의 차이를 중학생도 이해할 수 있게 설명해줘.
