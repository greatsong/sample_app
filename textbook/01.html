1장. 파일 구조 이해하기

어느 파일을 열어야 무엇을 바꿀 수 있는지 먼저 구분합니다.

목차이전 장다음 장

이번 목표

앱을 구성하는 파일 역할을 설명합니다. 코드를 전부 읽는 것이 아니라, 화면 구조, 디자인, 설정, API, 투표 저장, 프록시가 각각 어느 파일에 있는지 찾는 것이 목표입니다.

파일 역할

index.html
  화면의 큰 구조입니다. 제목, 카드 영역, 버튼 영역이 들어 있습니다.

css/style.css
  색상, 카드 모양, 간격, 모바일 배치를 담당합니다.

js/config.js
  학교, 정류소, 프록시 URL 같은 설정값을 모아 둔 설정판입니다.

js/adapters/api-services.js
  날씨, 급식, 버스 API를 실제로 호출합니다.

js/adapters/vote-store.js
  급식 투표를 Apps Script에 보내고 투표 수를 가져옵니다.

js/app.js
  버튼 클릭, 카드 그리기, 투표 처리, 설정 저장을 담당합니다.

apps-script/Code.gs
  버스 API 키와 Google Sheets 저장을 대신 처리하는 Apps Script 코드입니다.

따라하기

  1. GitHub 저장소 또는 프로젝트 폴더를 엽니다.
  2. 위 파일을 하나씩 찾습니다.
  3. 각 파일 옆에 화면, 디자인, 설정, API, 동작, 프록시 중 하나를 적습니다.
  4. 화면에 보이는 문구 하나가 어느 파일에서 오는지 찾아봅니다.

체크리스트

  • index.html을 찾았습니다.
  • js/config.js가 설정판이라는 점을 설명할 수 있습니다.
  • apps-script/Code.gs는 GitHub Pages가 아니라 Apps Script에 붙여넣는 코드라는 점을 압니다.

자주 나는 오류

  • config.js를 고쳤는데 화면이 안 바뀌면 저장 후 새로고침합니다.
  • 파일 이름 대소문자가 다르면 GitHub Pages에서 깨질 수 있습니다.
  • Apps Script 코드를 HTML에 붙이면 안 됩니다.
