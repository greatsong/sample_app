설정과 오류 해결

Apps Script, API 키, Console 오류, 수업 운영 체크리스트를 한곳에 모았습니다.

Apps Script 배포 체크

  • Script Properties에 BUS_API_KEY와 MEAL_VOTE_SHEET_ID를 넣었는지 확인합니다.
  • 웹 앱 URL은 /exec로 끝나는 주소를 사용합니다.
  • 코드를 수정한 뒤에는 반드시 새 배포 버전을 만듭니다.
  • 권한 승인이 필요한 경우 교사 계정으로 먼저 시연합니다.

키 관리 원칙

  • GitHub Pages에 올라간 HTML, CSS, JS는 누구나 볼 수 있습니다.
  • BUS_API_KEY 같은 비밀키는 GitHub에 올리지 않습니다.
  • Script Properties, 환경 변수, 교사용 서버 같은 별도 보관 장소를 사용합니다.
  • 발표 자료나 README에도 실제 키를 적지 않습니다.

오류를 줄이는 수업 운영

  • 첫 시간에는 배포 성공을 최우선으로 둡니다.
  • API 키가 필요한 장은 교사용 데모를 먼저 준비합니다.
  • 학생에게 한 번에 한 파일, 한 설정만 바꾸게 합니다.
  • 오류가 나면 화면, Console, Network, 바꾼 파일 순서로 확인합니다.
