Appendix

부록. Apps Script 설정과 오류 해결

학생 본문과 교사용 운영 내용을 분리해 정리합니다.

목차이전 장마무리

필요한 Script Properties

BUS_API_KEY
  서울 버스 API 키입니다. GitHub에 올리지 않습니다.

MEAL_VOTE_SHEET_ID
  급식 투표를 저장할 Google Sheets 스프레드시트 ID입니다.

BUS_ALERT_EMAIL
  교사용 5분 전 메일 알림을 받을 주소입니다. 선택 사항입니다.

BUS_ALERT_ARS_ID
  메일 알림에 사용할 정류소번호입니다. 선택 사항입니다.

BUS_ALERT_ROUTE_NAME
  메일 알림에 사용할 노선명입니다. 선택 사항입니다.

배포 설정

배포 유형: 웹 앱
실행 사용자: 나
액세스 권한: 모든 사용자

Apps Script는 코드를 저장했다고 배포 URL에 바로 반영되지 않을 수 있습니다. 수정 후에는 새 버전으로 다시 배포합니다.

교사용 확장: 5분 전 메일 알림

메일 알림은 권한 승인, 시간 기반 트리거, 이메일 발송이 들어가므로 학생 본문 실습이 아니라 교사용 운영 또는 확장 활동으로 다룹니다.

  1. Apps Script에 BUS_ALERT_EMAIL을 넣습니다.
  2. 필요하면 BUS_ALERT_ARS_ID와 BUS_ALERT_ROUTE_NAME을 넣습니다.
  3. 트리거 메뉴를 엽니다.
  4. checkBusAndSendMail 함수를 선택합니다.
  5. 시간 기반 트리거를 선택합니다.
  6. 분 단위 타이머, 1분마다로 설정합니다.
  7. 실제 메일이 오는지 확인합니다.

문제 해결

  • 화면이 안 열릴 때: GitHub Pages 주소, index.html 위치, 배포 완료 여부를 확인합니다.
  • 날씨가 안 나올 때: weather.enabled, 위도/경도, 쉼표를 확인합니다.
  • 급식이 안 나올 때: 교육청 코드, 학교 코드, mealCode, mealDate를 확인합니다.
  • 투표가 저장되지 않을 때: MEAL_VOTE_SHEET_ID, Apps Script 새 배포, Google Sheets 권한을 확인합니다.
  • 버스가 안 나올 때: BUS_API_KEY, /exec URL, 정류소번호, 노선명, localStorage를 확인합니다.

AI에게 다시 묻는 법

방금 준 코드가 내 프로젝트에서 오류가 났어.
내 파일 구조는 index.html, css/style.css, js/config.js, js/app.js야.
기존 기능을 유지하면서 가장 작은 수정만 제안해줘.
수정할 파일 이름과 바꿀 위치를 먼저 말해줘.
