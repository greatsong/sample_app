Chapter 2

2장. 날씨 API 붙이기

키가 필요 없는 Open-Meteo API로 첫 API 연결을 성공시킵니다.

목차이전 장다음 장

이번 목표

공개 API가 화면에 어떻게 표시되는지 확인합니다. Open-Meteo는 API 키가 없어도 사용할 수 있으므로 첫 실습에 적합합니다.

따라하기

  1. js/config.js를 엽니다.
  2. weather 설정을 찾습니다.
  3. label, latitude, longitude 값을 확인합니다.
  4. 서울 값을 다른 지역 값으로 바꿉니다.
  5. 저장하고 새로고침합니다.
  6. Console에 빨간 오류가 없는지 확인합니다.

기본 코드

weather: {
  enabled: true,
  label: "서울",
  latitude: 37.5665,
  longitude: 126.9780
}

부산으로 바꾸기

weather: {
  enabled: true,
  label: "부산",
  latitude: 35.1796,
  longitude: 129.0756
}

체크리스트

  • weather.enabled가 true입니다.
  • label을 바꾸면 화면의 지역 이름이 바뀝니다.
  • 위도와 경도를 바꾸면 날씨 값이 달라질 수 있습니다.
  • 위도와 경도 사이 쉼표가 유지되어 있습니다.

자주 나는 오류

  • 쉼표를 지우면 JavaScript 객체 문법이 깨집니다.
  • 지역명 따옴표를 지우면 글자가 변수처럼 해석됩니다.
  • 저장하지 않으면 브라우저 새로고침을 해도 바뀌지 않습니다.
